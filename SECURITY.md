# Security Policy

## Reporting a Vulnerability

Please report security vulnerabilities **privately to the maintainer first**, and do not open a public issue. Use GitHub's [private vulnerability reporting](https://github.com/mcpmark-eval-liuhezi/release-readiness-audit/security/advisories/new) on this repository, or contact the maintainer directly.

We aim to respond to a valid report within **90 days** of receiving it. Please allow a reasonable amount of time for the issue to be fixed and for a release to be published before any public disclosure.
